# Pluto product demo

[Watch the demo on the website](https://metagrover.github.io/get-pluto/#in-action) ·
[Open the video](media/pluto-demo.mp4) ·
[English captions](media/pluto-demo.en.vtt)

The approved 30.5-second, 1920 × 1080 demo shows the current Pluto interface
with fictional launch data. It opens with a message from Maya, follows a
standalone note and a meeting follow-up into the same workspace, then uses Ask
Pluto to find the Friday deadline and open the cited transcript passage.

The [English captions](media/pluto-demo.en.vtt) contain the narration.

## Published assets

- `docs/media/pluto-demo.mp4` — approved H.264/AAC video.
- `docs/media/pluto-demo-poster.jpg` — a frame from the approved video.
- `docs/media/pluto-demo.en.vtt` — browser-compatible English captions.

The same three files live under `assets/product/` in the sibling `pluto-site`
repository. The product README links the poster to the website player and
links directly to the repository MP4. Keep both copies in sync when replacing
the demo.

## Production notes

The walkthrough uses the preview build of Pluto’s actual interface with
fictional meeting data and a scripted Ask Pluto answer. The narration uses
ElevenLabs Kyle. Use fictional data for replacement footage.
