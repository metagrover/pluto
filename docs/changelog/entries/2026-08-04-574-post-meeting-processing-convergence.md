### Make post-meeting processing converge without false speech-loss warnings
- **Issue:** [#574](https://github.com/metagrover/pluto/issues/574)
- **PR:** [#575](https://github.com/metagrover/pluto/pull/575), [#576](https://github.com/metagrover/pluto/pull/576), [#577](https://github.com/metagrover/pluto/pull/577), [#578](https://github.com/metagrover/pluto/pull/578), [#579](https://github.com/metagrover/pluto/pull/579), [#580](https://github.com/metagrover/pluto/pull/580), [#581](https://github.com/metagrover/pluto/pull/581), [#582](https://github.com/metagrover/pluto/pull/582), [#583](https://github.com/metagrover/pluto/pull/583), [#584](https://github.com/metagrover/pluto/pull/584)
- **Changed:** Full-channel validation now distinguishes explicit VAD-confirmed silence from ambiguous empty transcription, preserves mic and system ASR coverage through canonical speaker arbitration, recording finalization hands validated meetings to one app-wide worker, downstream completion waits for entity extraction and synchronous knowledge refresh, and unavailable local diarization models use the deterministic fallback without a failed request. Transcript validation atomically persists a database-owned downstream lease, while later analysis and knowledge saves are fenced by that run ID and expired leases wake the worker without retry loops. Long-running Ollama requests use a process-local HTTP transport, all knowledge generation shares the local model's single generation slot, same-input refreshes coalesce from immutable snapshots, and successful documents persist their input fingerprint so restart recovery only reuses current knowledge.
- **Why:** Acoustic level windows were treated as proof of speech even after WhisperX found no speech, and processing depended on the selected meeting while analysis and knowledge could be marked complete too early.
- **Replaced:** Selection-triggered recovery, empty-segment inference, canonical-label-based source coverage, concurrent access to shared WhisperX model state, cross-meeting local-model contention, Electron network-service suspension during localhost generation, duplicate same-input knowledge synthesis, restart-time regeneration of already-covered documents, truncated knowledge JSON from undersized Ollama output context, renderer-local downstream ownership, unfenced derived saves, whole-meeting saves that erase MID knowledge, restart-from-zero downstream recovery, unnormalized V2 change summaries, inline post-stop analysis, and fire-and-forget knowledge completion.
- **Notes:** Capture gaps, source failures, and ambiguous VAD outcomes remain fail-closed; persisted integrity evidence contains only aggregate source outcomes and durations.
