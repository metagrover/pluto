### Make post-meeting processing converge without false speech-loss warnings
- **Issue:** [#574](https://github.com/metagrover/pluto/issues/574)
- **PR:** [#575](https://github.com/metagrover/pluto/pull/575), [#576](https://github.com/metagrover/pluto/pull/576), [#577](https://github.com/metagrover/pluto/pull/577), [#578](https://github.com/metagrover/pluto/pull/578), [#579](https://github.com/metagrover/pluto/pull/579), [#580](https://github.com/metagrover/pluto/pull/580), [#581](https://github.com/metagrover/pluto/pull/581), [#582](https://github.com/metagrover/pluto/pull/582), [#583](https://github.com/metagrover/pluto/pull/583), [#584](https://github.com/metagrover/pluto/pull/584), [#585](https://github.com/metagrover/pluto/pull/585), [#588](https://github.com/metagrover/pluto/pull/588), [#591](https://github.com/metagrover/pluto/pull/591)
- **Changed:** Full-channel validation now distinguishes explicit VAD-confirmed silence from ambiguous empty transcription, preserves mic and system ASR coverage through canonical speaker arbitration, recording finalization hands validated meetings to one app-wide worker, downstream completion waits for entity extraction and synchronous knowledge refresh, and unavailable local diarization models use the deterministic fallback without a failed request. Transcript validation atomically persists a database-owned downstream lease, while later analysis and knowledge saves are fenced by that run ID and only the head meeting can schedule a lease-expiry wake. Long-running Ollama requests use a process-local HTTP transport, every local generation waits for the model's single slot before its timeout starts, same-input knowledge refreshes coalesce from immutable snapshots, and successful documents persist their input fingerprint so restart recovery only reuses current knowledge. Whole-meeting persistence now updates the existing parent row instead of replacing it, so later lease and completion saves cannot cascade-delete entity associations; generic recovered and untitled meetings also re-enter title generation without overwriting existing analysis. Meetings with a proven capture gap and a substantial persisted transcript now generate explicitly partial analysis, entities, and knowledge under an exact transcript-and-integrity source proof without being misrepresented as validated.
- **Why:** Acoustic level windows were treated as proof of speech even after WhisperX found no speech, and processing depended on the selected meeting while analysis and knowledge could be marked complete too early.
- **Replaced:** Selection-triggered recovery, empty-segment inference, canonical-label-based source coverage, concurrent access to shared WhisperX model state, cross-meeting local-model contention, Electron network-service suspension during localhost generation, duplicate same-input knowledge synthesis, restart-time regeneration of already-covered documents, truncated knowledge JSON from undersized Ollama output context, renderer-local downstream ownership, unfenced derived saves, destructive SQLite parent replacement, whole-meeting saves that erase MID or entity knowledge, restart-from-zero downstream recovery, unnormalized V2 change summaries, inline post-stop analysis, and fire-and-forget knowledge completion.
- **Notes:** Capture gaps, source failures, and ambiguous VAD outcomes remain fail-closed for transcript validation. Missing speech is never fabricated or marked complete; partial downstream processing remains single-flight and persisted provenance stays content-free.
