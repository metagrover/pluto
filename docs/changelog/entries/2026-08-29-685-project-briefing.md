### Turn Projects into evidence-backed briefings

- **Issue:** [#685](https://github.com/metagrover/pluto/issues/685)
- **PR:** Not created; implementation branch `codex/685-project-briefing`.
- **Changed:** Qualified project pages now lead with an editable human title, meeting and attendance analytics, a conservative current read, explicit milestones, recurring meeting patterns, commitments, and source evidence. The overview carries the same health, cadence, and milestone signals without becoming a card dashboard.
- **Why:** Projects exposed grounded scope but still read like extracted database records. They lacked fast re-entry signals, editable user vocabulary, honest progress interpretation, recurring-meeting recognition, and a safe way to reunite subprojects.
- **Replaced:** Long immutable detected titles, undifferentiated project rows, placeholder dossier content, and separate project identities that users could not reconcile.
- **Notes:** Attendance excludes synthetic speakers and discloses coverage. Recurrence needs three consistently spaced observations. Falling behind requires overdue confirmed work; missing evidence stays unknown instead of becoming green. Merging retains every source record and supports persistent undo.
