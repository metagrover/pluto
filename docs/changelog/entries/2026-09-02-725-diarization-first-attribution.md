- **Display repair:** Completed recovered transcripts now render canonical segments only. Retained live evidence cannot resurrect obsolete local-speaker labels, rejected text, or speech after a final no-speech result; unfinished and legacy transcript reconciliation is unchanged.
- **Explicit retry:** The finalizer accepts an explicit manual retry for completed results while retaining capture-generation, active-run, source-digest, and canonical-validation checks. Automatic calls still cannot repeatedly reprocess completed v2 transcripts.
- **Capture repair:** Normal System capture uses a global output tap so call processes created after recording starts remain included; targeted probes remain targeted. The tap-only aggregate excludes physical microphone inputs, reads its actual input format after startup, validates buffer channels, and rebuilds on guarded format changes. Quiet startup delivers PCM without waiting for playback. Startup waits for PCM; exhausted native recovery and unexpected exits remain visible and durably invalidate source coverage, while a delayed renderer alone cannot create missing-audio evidence. Stale renderer permission labels cannot override fresh readiness. Failure evidence that cannot be saved blocks sealing.
- **Recovered audio:** Decode each journal chunk using its own format and anchor it to its journal interval so sample-rate changes and reconnect waits retain timing and late audio. Partially missing inputs fail instead of producing a truncated successful recording; sparse mixing bounds concurrent inputs.
- **Live echo:** Reconciliation handles differing microphone/System turn boundaries while retaining raw evidence, revisions, and distinct local additions. Original live rows and native word timings persist separately from the merged preview. Bounded sequence alignment and independently correlated PCM envelopes handle recognition substitutions and merged or split words in long echo spans; critical differences and local insertions remain visible. Exact continuation can skip words recognized only by System when a long measured anchor and each source word onset agree; padded silent intervals cannot justify removal. Closely aligned word onsets handle a final echo word whose timestamp stretches through a pause, without rewriting raw timings or removing a later local repetition. Overlapping acoustic windows avoid capture-boundary false negatives without lowering confidence thresholds or counting shared speech twice. Source-clock and session guards keep evidence isolated, and delayed acoustic evidence refreshes only the live presentation. Remaining local speech uses its own displayed word time and follows the remote turn instead of inheriting the removed echo’s earlier timestamp. Final echo cleanup preserves the System counterpart of mic words already removed acoustically.
- **Packaged recording:** FFmpeg and ffprobe launch from their unpacked executable paths. Package verification executes both tools; saved-status updates forward the meeting ID rather than the Electron event object.
- **Capture trust:** Finalization requires a complete sealed System reference before treating surviving mic speech as verified local speech. Healthy captured silence remains valid. Failed retries preserve saved text and cannot resurrect obsolete live evidence. Incomplete or unverifiable System capture receives an explicit explanation instead of implying another transcription pass can recreate missing audio. Native, FFmpeg, DOM, and database regressions cover these boundaries; fresh real-call acceptance remains separate, and absent historical participant audio cannot be reconstructed.

The existing acceptance threshold stays unchanged. The transcript view distinguishes ready text from unresolved remote labels.
