### Make saved Ask Pluto answer from meeting notes

- **Issue:** [#699](https://github.com/metagrover/pluto/issues/699)
- **PR:** Not created yet.
- **Changed:** Saved-meeting Ask Pluto now searches a dedicated, rebuildable notes index containing effective generated notes, user-authored notes, user edit overlays, and structured meeting intelligence. Both global and meeting-scoped chat exclude transcript-derived ranking, snippets, context, and citations for ordinary questions. Explicit quotation requests receive only a bounded recent transcript window, while meetings without usable notes can use a clearly disclosed weak transcript fallback. Active-recording chat remains transcript-backed. Saved Fast and Deep synthesis stay on the configured general Gemma model instead of swapping through Phi; active-meeting chat and query classification retain the quick model. Safe summaries, decisions, action-item recall, and assignee lookups return existing structured evidence without model generation. Model-backed responses can include up to four supported points, with citation-validated claims appearing progressively. One provider-neutral main-process coordinator owns local inference priority, cancellation, serialization, and content-free queue timing. Packaged Pluto acquires a single-instance lock before importing database code, while development explicitly uses a separate user-data profile.
- **Why:** The former mixed FTS index and completed-meeting context always admitted transcript text, so a prompt-level notes preference could not guarantee notes-first answers. Transcripts were also far larger than saved notes and model swapping added avoidable local latency.
- **Replaced:** Mixed transcript/notes retrieval, unconditional saved transcript excerpts, routine Phi-to-Gemma switching between completed Fast and Deep chat, provider-local admission branching, a suggested assignee question that unnecessarily required generation, generic model-availability errors for unrelated failures, static waiting feedback, and multiple packaged processes opening the production profile.
- **Notes:** The source notes and transcripts are not regenerated or rewritten. Ask Pluto distinguishes searching, waiting for local inference, writing, and source checking in one compact response shell with a four-stage phase rail, answer-shaped skeletons, and reduced-motion-safe feedback. Timeouts, unreachable providers, invalid model responses, and other generation failures retain the question and expose distinct recovery copy. Streaming remains behind citation validation, so unsupported draft prose never becomes a visible completed answer. The initial runtime remains serialized Ollama. Same-model parallel decoding and direct llama.cpp or MLX runtimes remain gated follow-up evaluations after the complete production path meets semantic, latency, and memory acceptance criteria.
