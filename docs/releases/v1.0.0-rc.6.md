# Pluto 1.0.0-rc.6

## Setup and release verification

- Setup now distinguishes native-runtime failures from model download/verification failures and shows a shareable setup code. Failure diagnostics are also saved in Pluto's local startup log.
- Both first-run setup and the startup gate use the same recovery guidance. Existing profiles and verified model downloads are preserved.
- Releases now require a real model preparation from the packaged runtime with an empty cache, followed by a separate restart that must reuse the installed models without downloading again.

## Installation

Download the Apple Silicon macOS DMG attached below. SHA256SUMS.txt contains its checksum.

This release is ad-hoc signed and is not notarized. If macOS says it cannot verify Pluto, choose Done, then System Settings → Privacy & Security → Open Anyway for Pluto. See [Apple's instructions](https://support.apple.com/102445). Developer ID signing and notarization require Apple credentials that are not configured for this project.

For a completely fresh test, use a separate profile so your existing meetings and settings remain safe. Permissions belong to the app identity and may need resetting separately.
