# Pluto 1.0.0-rc.8

## Fixes

- Recording admission now receives the verified system-audio permission, fixing the false “Recording could not start securely” rejection.
- Permission checks refresh when returning to Pluto and with Check again, without unconditionally restarting the app. Previously denied microphone access enabled in System Settings can still require restarting under macOS.
- The permissions dialog scrolls within the window and keeps its actions visible.
- The installer resets only Pluto permission decisions when an ad-hoc build identity changes, avoiding stale grants. `--fresh-profile` also resets Pluto permissions for first-run testing.

- Cached Parakeet installs now pass the application IPC validator instead of failing with `parakeet_protocol_invalid`. Verified models are reused on restart.
- ChatGPT Desktop discovery no longer uses AppleScript or asks for Automation access.
- Browser meeting detection now requires explicit opt-in in Settings → Meetings. Unavailable inspection does not trigger automatic recording stop.
- Packaged setup verification now runs through the actual application client for both an empty cache and a separate cached restart.
- The installer supports `--fresh-profile` to test onboarding in a separate empty profile while preserving existing meetings, settings, and models.

## Install

During private testing:

```sh
gh api -H 'Accept: application/vnd.github.raw+json' repos/metagrover/pluto/contents/scripts/install-macos.sh | bash
```

Once the repository is public:

```sh
curl -fsSL https://raw.githubusercontent.com/metagrover/pluto/master/scripts/install-macos.sh | bash
```

Quit Pluto before upgrading. The installer verifies the release checksum and app signature, installs and launches Pluto, and removes only Pluto's quarantine. It preserves existing profiles and models. When an ad-hoc signing identity changes, it resets only Pluto’s permission decisions so the new build can request access. Running it explicitly trusts this unnotarized build.

To simulate first-run onboarding without changing an existing profile, use `bash -s -- --fresh-profile` at the end of either command. An empty profile has its own model download. Normal launches retain the existing profile.

Apple Silicon and macOS 14.2 or later are required. This release is ad-hoc signed, not Developer ID notarized. Manual DMG installs still require macOS Open Anyway. Microphone, system audio, and optional calendar access remain explicit macOS permission steps.
