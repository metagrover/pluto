# Pluto 1.0.0-rc.20

Release candidate for testing.

## Changes

- Reuse an existing project for equivalent names when shared meeting evidence identifies one clear match. Preserve reviewed project details and keep ambiguous matches separate. ([#872](https://github.com/metagrover/pluto/pull/872))
- Add a 45-second product demo that plays directly in the README. Simplify setup instructions and remove obsolete documentation. ([#873](https://github.com/metagrover/pluto/pull/873), [#876](https://github.com/metagrover/pluto/pull/876))

## Install or update

Quit Pluto, then run:

```sh
curl -fsSL https://raw.githubusercontent.com/metagrover/pluto/master/scripts/install-macos.sh | bash
```

The installer verifies the download and app signature before replacing Pluto.
Existing profiles and models are preserved. You can also download the Apple
Silicon DMG below. Requires macOS 14.2 or later.

This build is ad-hoc signed and is not Apple-notarized. macOS may request recording
permissions again after upgrading. Keep a backup of your profile before updating.
