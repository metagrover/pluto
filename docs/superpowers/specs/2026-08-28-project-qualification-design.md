## Approved extension: source-grounded initiative discovery

The legacy corpus is dominated by phases, workstreams, and discussion labels. Conservative review must not promote those labels merely because their source mentions a broader outcome. The user approved a separate source-centered discovery pass on 2026-08-28.

Discovery reviews one validated source conversation at a time. It may create one new project entity only when that single conversation contains exact quotations establishing a distinct outcome and at least two non-overlapping constituent work packages. The normal qualification validator remains the authority: malformed, unsupported, overlapping, or uncertain proposals create nothing.

The new initiative uses a deterministic ID derived from the source meeting and grounded outcome quote, links back to that meeting, and carries the same versioned qualified metadata used elsewhere. Replays are idempotent. Existing entities are never renamed, deleted, merged, or attached as children automatically. Direct membership evidence remains required for any later association, and user edits to an already-created initiative win over rediscovery.

Discovery progress is durable per source revision so an empty or uncertain source does not loop on every visit. Failed provider calls remain retryable. The overview runs discovery before legacy candidate review and publishes each qualified initiative immediately, while keeping all pre-existing material in the secondary list.

For long conversations, evidence retrieval centers excerpts on the project fragments already linked to that source. This affects only which verbatim passages reach the model; qualification still requires exact quotes against the full validated transcript, and candidate labels never establish scope by themselves.

The bounded queue schedules sources with multiple extracted fragments and planning-oriented titles first so likely portfolio material appears sooner. This ordering is not a qualification signal and cannot create or modify an entity without the same grounded semantic assessment.

Constituent work packages are distinct components of the same initiative, not separate initiatives. The model prompt states this explicitly; deterministic validation still rejects duplicated, overlapping, or unsupported components.

Qualification is independent of lifecycle: a grounded initiative may be planned, active, or completed. Discovery never requires completion and does not infer lifecycle from missing tasks.

Qualification is semantic rather than label-based. A conversation need not formally name an initiative or provide a roadmap; an experiment, strategy, program, or approach qualifies when exact source evidence establishes one distinct outcome and two cohesive actions.
