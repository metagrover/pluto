# Ask Pluto local latency and grounding benchmark

Date: 2026-08-25
Issue: [#62](https://github.com/metagrover/pluto/issues/62)
Model: `qwen3.5:9b` (`Q4_K_M`)
Host: Apple M1 Pro, 16 GB unified memory

## Acceptance run

The benchmark keeps one local model resident and runs five Fast and five Deep
synthetic meeting-evidence questions. First-token timing begins immediately
before answer generation and ends on the first visible `response` token;
hidden reasoning tokens do not count. Each answer must also contain the expected
names, dates, state change, risk, and source references.

Command:

```bash
pnpm run benchmark:ask-pluto -- --runs 5
```

| Mode | Visible first-token p95 | Target | Total p95 | Grounding checks |
| --- | ---: | ---: | ---: | --- |
| Fast | 116 ms | <= 5,000 ms | 1,017 ms | 5/5 passed |
| Deep | 4,725 ms | <= 15,000 ms | 9,928 ms | 5/5 passed |

The first Deep sample includes the one-time context expansion from 8K to 16K;
subsequent first-token measurements were 105-121 ms.

## Electron acceptance

The final desktop run opened Ask Pluto while background title generation was
active and asked a direct question about `current meeting`. Pluto preempted the
title task, resolved the latest persisted meeting, restricted generation to that
single frozen source, emitted its first visible token in 689 ms, and completed
in 4,402 ms. The citation auditor conservatively displayed `Needs review` for
one unsupported synthesis claim instead of overstating trust. A separate Deep
comparison cancellation settled end to end in 16 ms and restored the composer.

## Rejected configurations

- Deep with hidden thinking and a 2,048-token output budget completed without
  producing a visible answer.
- Deep with hidden thinking and a 4,096-token output budget produced its first
  visible token at 124,297 ms and completed at 127,979 ms.
- A separate model-based intent-classification request added roughly nine
  seconds before each answer and caused Fast mode to miss its five-second
  target.

## Resulting runtime contract

Fast and Deep both disable hidden thinking on this local model. Deep retains the
larger 16K evidence context, the 2,048-token answer budget, current-meeting
pinning, cross-meeting retrieval, and comparative citation rules. Intent routing
is deterministic in the synchronous Ask Pluto path. While chat is open,
background knowledge synthesis remains paused; direct current/latest lookups and
factual cited follow-ups use only their frozen meeting evidence, and background
title generation is preemptible.
